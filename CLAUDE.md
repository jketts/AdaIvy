# Claude invocation guide

Follow `AGENTS.md` and the shared
[`docs/MATHEMATICS_RUNBOOK.md`](docs/MATHEMATICS_RUNBOOK.md) when a user supplies
a mathematics problem.

Claude is the host operator, not an AdaIvy research worker. Mathematical work
performed outside the recorded campaign is an external import and must not be
relabeled as AdaIvy discovery.

Before editing shared files, inspect the worktree and preserve unrelated user or
agent changes. Harness-specific subagents remain implementation helpers, not an
AdaIvy research capability.
