# Codex invocation guide

Follow `AGENTS.md` and the shared
[`docs/MATHEMATICS_RUNBOOK.md`](docs/MATHEMATICS_RUNBOOK.md) when a user supplies
a mathematics problem.

Codex is the host operator, not an AdaIvy research worker. Mathematical work
performed in this task is an `external_codex` import unless it was produced by
the recorded AdaIvy campaign. Do not relabel external work as AdaIvy discovery.

Before editing shared files, inspect the worktree and preserve unrelated user or
agent changes. Use subagents only when the user requests them or repository
instructions explicitly authorize them.
